## 如何更新网站

### 1. 换照片

把婚纱照按上面的文件名放进 `assets/images/`，提交并推送即可：

```bash
git add assets/images/
git commit -m "更新婚纱照"
git push
```

照片未放置时，页面会显示优雅的占位样式，不影响访问。

> 建议先用图片工具把照片压缩到 300KB 以内再上传，加载更快。

### 2. 换背景音乐

把音乐文件命名为 `bgm.mp3` 放进 `assets/music/`，提交推送即可。
未放置时音乐区域自动隐藏。

### 3. 开启 GitHub Pages（只需一次）

1. 打开仓库页面 `https://github.com/Bonn12138/wedding`
2. 进入 **Settings → Pages**
3. **Source** 选择 `Deploy from a branch`
4. 分支选 `master`，目录选 `/ (root)`，点 **Save**
5. 等待 1–2 分钟，即可通过上面的地址访问

### 4. RSVP 登记收集（腾讯问卷 + 信息预填）

宾客在请柬页面填好姓名/住宿/电话后点「一键登记」，已填信息会**自动带入问卷**对应题目，
宾客只需在问卷里点一下"提交"——不用重新打字。

**设置步骤：**

1. 打开 [wj.qq.com](https://wj.qq.com)，微信扫码登录（免费）
2. 创建问卷 → 类型选「登记」或「活动报名」，加三个题：
   - 您的姓名（单行填空，必答）
   - 是否需要住宿（单选：需要 / 不需要 / 待定，必答）
   - 联系电话（单行填空，选答）
3. **关键一步 — 开启链接传参**：编辑问卷时，进入每道题的设置，
   找到「链接传参 / 参数名」（部分版本在"设置 → 参数预填"里），分别给三道题设置参数名，
   建议：姓名题 `name`、住宿题 `stay`、电话题 `phone`
   （若找不到该选项，说明当前版本将该功能放在了会员档位，见下方说明）
4. 发布后复制链接，填进 `index.html` 的 `SURVEY_URL`，参数名对应填进 `PREFILL_PARAMS`
5. push 后用手机实测一次：在请柬填"张三/需要/138xxx"，点「一键登记」，
   问卷打开时应已带入这三项

**如果问卷打不开预填（参数没生效）**：腾讯问卷的链接传参功能可能需要会员，
或参数名没保存成功。此时预填不生效，但页面会正常跳转到问卷，宾客手动填写即可，
不影响收集。可以在问卷里把三道题做成必答，保证信息完整。

**数据查看**：腾讯问卷后台实时可见所有回复，可导出 Excel，按"需要住宿"筛选人数订房。

**纯本地模式（备用）**：`SURVEY_URL` 留空时为页面内本地登记，数据存在访客浏览器
localStorage，你们收不到，仅适合演示。

**其他备选：**

| 方案 | 说明 |
|------|------|
| [问卷星](https://www.wjx.cn) | 与腾讯问卷同类，免费版够用 |
| Google Forms | 国内打不开，仅海外宾客适用 |
| [Formspree](https://formspree.io) | 表单原样保留，提交结果发到邮箱，免费 50 条/月，海外服务 |
| 微信群接龙 | 完全零代码，适合长辈场景，但统计要手动数 |
